# Changelog

## 1.0.0

First public version.

- Phone app (Expo / React Native, Android) with the White Milky and Chocolate Milk themes.
- PC website (`web/`): a local Node server plus a themed page that plays the phone's microphone to the output you choose (VB-Cable).
- Pairing code (made once, kept on the PC), UDP discovery, auto-reconnect, remembered PC and theme.
- Demo mode for Expo Go (`EXPO_PUBLIC_MOCK=1`).
- Known gaps: no echo or noise cancellation, no encryption, not yet tested on real hardware.
